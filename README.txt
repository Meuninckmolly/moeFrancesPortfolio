MOLLY MEUNINCK — PORTFOLIO REFRESH

WHAT'S INCLUDED
- index.html: homepage with 8 projects
- about.html and contact.html: about and contact pages
- print.html and digital.html: project category pages
- project-*.html: 8 individual project case-study pages
- styles.css: shared responsive styling
- script.js: mobile navigation behavior
- images/: add your actual portfolio images here

DESIGN UPDATES
- Removed the Adobe font dependency; the site uses DM Sans and standard fallbacks.
- Removed the yellow circular sticker from the homepage.
- Each of the 8 projects has a dedicated HTML page linked from the homepage.
- Kept the overall interface neutral, with brighter colors mainly in project artwork.

HOW TO OPEN
1. Unzip the downloaded folder.
2. Open the folder in VS Code.
3. Open index.html and use Live Server, or open index.html in a browser.

CUSTOMIZE
- The project art blocks are placeholders, not your actual portfolio work. Replace them with your final images.
- Put image files inside images/ and update each project's HTML to use those image paths.
- In contact.html, replace your-email@example.com with your actual email if that placeholder is present.
- Update the project descriptions so they accurately reflect your role and final outcomes.
